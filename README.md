# App Cocina

Prototipo de web app (PWA) para iPhone: despensa, plan semanal de comidas y lista de compras del mes.

- Abre el link de GitHub Pages en **Safari**, toca **Compartir → Agregar a inicio**.
- Los datos se guardan solo en el teléfono. Exporta un respaldo JSON desde Más › Ajustes cada una o dos semanas.
- Sin servidor ni cuentas. Todo el código está en `index.html`; `sw.js` permite usarla sin internet.
